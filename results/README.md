# Computational results

This directory is the retained, reviewer-facing output of the workflow. Every
file is either generated by a declared Snakemake rule or documents the identity
and integrity of those products.

| Directory | Contents | Primary formats |
|---|---|---|
| [`analysis/`](analysis/) | One directory per scientific analysis | CSV, JSON |
| [`figures/`](figures/) | Five main and three supplemental figures | PDF, PNG |
| [`tables/`](tables/) | Tidy publication result ledger | CSV, Parquet |
| [`provenance/`](provenance/) | Frozen-input identities and runtime versions | JSON |
| [`audit/`](audit/) | Terminal numerical and figure-integrity report | JSON |

Restartable shards, logs, and benchmark files are created under `work/`,
`logs/`, and `benchmarks/` during execution. They are excluded from version
control because they are execution state rather than scientific products.

Do not edit retained results directly. Rebuild the relevant target through the
workflow and regenerate the terminal audit.
