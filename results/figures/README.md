# Figures

The workflow renders five main figures and three supplemental figures in two
formats:

- PDF provides the publication-quality vector artwork.
- PNG provides a 400 dpi raster preview for browsers and review systems.

All panels consume declared analysis products. `figure_manifest.json` records
the byte size and SHA-256 digest of every render; the terminal audit verifies
the complete set.
