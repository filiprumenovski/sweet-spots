# Reproducibility renders

These figures are generated entirely from declared Snakemake products. They are
the auditable render set, not a silent replacement of the current submission
PDFs. Several current submission legends still describe older panel designs;
reconcile and adopt panels explicitly before rebuilding the manuscript PDF.

`figure_manifest.json` records the SHA-256 digest and byte size of every PDF and
PNG. The final workflow audit verifies those hashes.
