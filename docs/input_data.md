# Frozen input data

The workflow consumes one immutable, analysis-ready input tree. Its
authoritative machine-readable identity record is
`results/provenance/input_manifest.json`, which records every relative path,
byte count, SHA-256 digest, and directory-tree digest.

## Open input bundle

Release `inputs-v1` contains 221,552,078 uncompressed bytes. The deterministic
archive has SHA-256 digest
`4010a15610f2a8d62c5f6ae0728249bf6f21353e42477ebfd359cb8d4c0fd3e8`.
It contains:

- canonical UniProtKB/Swiss-Prot sequence tables and three UniProt-derived
  non-rice species subsets;
- OMA-derived ortholog alignments;
- residue-level IUPred predictions generated for the canonical sequences;
- original PDBx/mmCIF structure files from the PDB archive;
- the OGT sequence and ortholog alignment; and
- the archived consensus-region object generated by this project.

UniProt database content is distributed under
[CC BY 4.0](https://www.uniprot.org/help/license). OMA data is distributed under
[CC BY 4.0](https://omabrowser.org/oma/terms_of_use/). Files in the PDB archive
are distributed under
[CC0 1.0](https://www.rcsb.org/pages/usage-policy). Downstream users must retain
the corresponding scientific citations and observe third-party rights noted by
those providers.

Install the archive with `scripts/fetch_open_inputs.sh`. The script downloads
the fixed release URL, verifies its digest before extraction, and never silently
substitutes a newer database release.

[download page](https://oglcnac.org/atlas/download/). MSU/RGAP protein sequences

[download interface](https://rice.uga.edu/downloads_gad.shtml).

[licensing page](https://www.phosphosite.org/staticLicensing). The repository
contains no credentials, licensed source records, or mechanism that bypasses
provider access controls.

The unified PTM parquet contains 41,615 dbPTM acetylation records, 16,418 ODB
O-GlcNAc records, 230,303 PhosphoSitePlus phosphorylation records, and 62,673
dbPTM ubiquitination records. Because those records share one analysis-ready
file, the entire parquet is treated as restricted.

## Verification

After adding the three user-supplied files, verify the complete tree before
launching any analysis:

```bash
uv run snakemake --snakefile workflow/Snakefile --profile profiles/local \
  results/provenance/input_manifest.json
```

The rule fails closed on a missing path or changed file identity.
